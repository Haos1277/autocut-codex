# Установка и приёмка

Эта инструкция предназначена ассистенту с доступом к локальному компьютеру. Не требуется устанавливать Claude Code. Исходные README в docs/upstream сохранены как история и не заменяют эту инструкцию.

1. Клонируйте https://github.com/Haos1277/autocut-codex в новую папку. Запишите `git rev-parse HEAD`. Перед выполнением изучите код. При повторной установке не перезаписывайте существующую копию без согласия владельца.
2. Проверьте Python 3.10+ (совместимость пакетов проверяется фактической установкой), `ffmpeg`, `ffprobe`. Нужны кодеки libx264, prores_ks и фильтр subtitles/libass для впечатывания субтитров. Проверьте шрифт с кириллицей. Устанавливайте недостающее подходящим для ОС пакетным менеджером с соблюдением разрешений пользователя; не меняйте системный Python. macOS: Homebrew, Linux: пакетный менеджер дистрибутива, Windows: доступный менеджер или официальные установщики. Не устанавливайте пакетные менеджеры молча.
3. Скопируйте всю папку `autocut` в пользовательскую `~/.agents/skills/autocut` (Windows: `.agents/skills/autocut` в домашней папке пользователя). LICENSE и requirements.txt должны остаться внутри установленного скилла.
4. Создайте `.venv` внутри установленной папки: `python3 -m venv .venv` (Windows: `py -3 -m venv .venv`). Установите зависимости выбранным интерпретатором: `<python-окружения> -m pip install -r requirements.txt`. Не копируйте чужую .venv.
5. В macOS/Linux интерпретатор — `.venv/bin/python`; в Windows — `.venv/Scripts/python.exe`. Все примеры `python scripts/...` из SKILL.md означают этот интерпретатор, запущенный из корня папки скилла. При отсутствии окружения сначала завершите установку.
6. Проверьте `pip check`, импорт `faster_whisper, numpy, scipy, PIL`. Из корня клонированного репозитория выполните `<python-окружения> -m unittest discover -s tests -v`. Эти тесты проверяют код в клоне; убедитесь, что установленная копия scripts совпадает с ним. Проверьте `compileall` для установленной scripts.
7. В отдельной временной папке создайте короткое однотонное видео через ffmpeg lavfi, карточку с кириллицей через cards.py и план с `layout: over`. Запустите compose.py с `--render`, проверьте ffprobe, просмотрите кадр: фон должен оставаться видимым вне букв. Для PNG проверьте RGBA и прозрачные пиксели; для анимации — ProRes и yuva. Пользовательские материалы для теста не нужны.
8. Распознавание требует скачивания модели. Согласуйте модель/объём и только затем проверяйте transcribe.py на разрешённой короткой записи с речью. Импорт библиотеки не равен успешной проверке распознавания. Без видео пользователя полная приёмка монтажа остаётся незавершённой.
9. Проверьте, видит ли ассистент скилл по имени `autocut`. Если не видит, откройте новую задачу; если не помогло — полностью закройте и откройте Codex. Проверьте обнаружение повторно, не обещайте срабатывание только по наличию папки.
10. Проверьте наличие встроенного ImageGen отдельно. Отсутствие генератора не мешает локальным карточкам и монтажу с готовыми изображениями. Не подключайте резервный gen_image.py, платные API, Remotion или LTX автоматически.

## Обновление

Обновляйте клон через Git, сравните изменения и локальные правки установленного скилла, согласуйте замену, затем повторите проверки. Не удаляйте старую установку и её окружение ради обновления без согласия.

## Ожидаемый отчёт

ОС, путь установки, commit, версии Python/ffmpeg, результат зависимостей и тестов, результат композиции, доступность ImageGen, статус проверки распознавания. Явно перечислите непроверенные функции. Никаких API-ключей в отчёте.
